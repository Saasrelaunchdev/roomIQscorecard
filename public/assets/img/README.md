# Pictures

One file per width: `<name>-<width>.webp` (for example `hero-800.webp` and `hero-1200.webp`). Content names a picture by
`<name>` (content/landing.mjs hero.picture, report points' img; content/brand.mjs reportImages takes `<name>-<width>`).
A missing picture is left out of the page, so the funnel builds before its art exists. docs/IMAGE-PROMPTS.md holds the
prompts that made them.
